## 🌟 Featured Projects

### 🏛️ TKT Smart Contract Suite — Tokenized Real Estate Investment Protocol
A 5-contract modular DeFi protocol on Ethereum that tokenizes real estate projects through ERC-20 tokens. Features a weighted-average holding timestamp mechanism, two-phase reversible burns for investor exits, and atomic 75/20/5 fund allocation across real estate, staking, and development pools. Deployed and verified on Sepolia.
> **Role:** Smart Contract Developer (Contributor)
> **Stack:** Solidity 0.8.20 · Hardhat · OpenZeppelin v5 · SafeERC20 · Ethers.js

### 🏠 Property Auction & Bidding Smart Contract
A blockchain-based property auction system supporting reserve pricing, accumulative bidding, anti-sniping deadline extensions, and pull-based escrow refunds. Hardened with ReentrancyGuard, Ownable, and two-step timelock fee updates.
> **Stack:** Solidity · Hardhat · OpenZeppelin · IPFS · Ethereum

### 🎨 ArtKidz — Solana NFT Creation Studio & Marketplace
A Web3 platform for children to create digital art, mint it as NFTs, and trade securely on a kid-safe Solana marketplace. Combines an ArtPad Studio (layers, stamps, 3D drawing via Three.js), AI image generation with OpenAI GPT-Image 1.5, voice-controlled drawing, and Anchor-based marketplace contracts with SPL token integration.
> **Stack:** Next.js 16 · TypeScript · Solana · Anchor · Metaplex/UMI · Dynamic Labs · OpenAI · Pinata/IPFS

### 🖼️ NFTs Alley — Multichain NFT Marketplace & Launchpad
A complete multichain NFT marketplace and launchpad supporting Ethereum and Base. Features ERC-721 and ERC-1155 contracts with royalty support, a Launchpad Factory for collection deployment, and real-time event indexing via The Graph subgraphs.
> **Role:** Sole Developer
> **Stack:** Solidity · Hardhat · The Graph · Next.js · Ethers.js · viem

### 🚀 WeJump — Solana Meme-Token Launchpad
An end-to-end Solana meme-token launchpad with token creation, create-and-buy flows, mint authority handling, and safe transaction rebuilds. Integrates Phantom and Solflare via Reown AppKit with hardened signing.
> **Role:** Sole Creator & Lead Engineer
> **Stack:** Next.js 14 · Solana · Raydium LaunchLab SDK v2 · Reown AppKit · MongoDB · Pinata/IPFS

### 🌐 Asvoria — Web3 Marketplace Integration
Led Web3 integration for a multi-chain marketplace platform — wallet connectivity, smart contract interactions across EVM and Solana, and a scalable database layer with SimpleHash API for metadata indexing.
> **Stack:** Solana · Ethereum · Base · Dynamic.xyz · WalletConnect · React · AWS · DynamoDB
